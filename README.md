# 俄罗斯方块游戏

仓库地址 http://github.com/hill-feng/-
本仓库包含一个基于 `pygame` 的带有排行榜和开始菜单的俄罗斯方块游戏。

## 功能特性

### 1. **开始菜单**
   - 主菜单界面显示三个按钮
   - 支持鼠标点击和悬停效果
   - 快捷键：ESC 可退出游戏

### 2. **游戏玩法**
   - **移动**：A/D 或左右方向键
   - **旋转**：W 键
   - **下落**：S 键
   - **快速下落**：Space 键
   - **返回菜单**：ESC 键

### 3. **排行榜系统**
   - **查看排行榜**：在主菜单点击"Leaderboard"按钮
   - **显示内容**：排名、玩家名称、分数、等级
   - **持久化存储**：分数自动保存到 `leaderboard.json` 文件
   - **自动排序**：按分数从高到低排列，保留前20名

### 4. **游戏结束流程**
   - 游戏结束时显示最终分数
   - 可选择保存分数到排行榜
   - **按 SPACE**：进入名称输入界面
   - **按 ESC**：返回主菜单而不保存
   
### 5. **名称输入界面**
   - 支持输入自定义玩家名称（最多15个字符）
   - 点击"Save"按钮或按 ENTER 保存分数
   - 点击"Skip"按钮以"Anonymous"身份保存分数
   - 按 BACKSPACE 删除字符

## 文件说明

- **main.py** - 游戏主程序
- **leaderboard.json** - 排行榜数据文件（自动生成）
- **README.md** - 本文件

## 游戏界面流程

```
开始菜单
  ├─ Start Game → 游戏进行 → 游戏结束 → 名称输入 → 返回菜单
  ├─ Leaderboard → 查看排行榜 → 返回菜单
  └─ Quit → 退出游戏
```

## 游戏规则

- 消除完整的一行得100分（一次消除多行有额外加分）
- 消除2行：300分，3行：500分，4行：800分
- 每消除10行升一级，难度加快
- 当新方块无法放入时游戏结束

## 分数系统

| 消除行数 | 得分 |
|---------|------|
| 1行 | 100分 |
| 2行 | 300分 |
| 3行 | 500分 |
| 4行 | 800分 |

## 运行游戏

```bash
python main.py
```

## 依赖

- pygame-ce 或 pygame
- Python 3.6+

## 提示

- 鼠标悬停在按钮上会改变颜色
- 输入名称时按 BACKSPACE 删除最后一个字符
- 排行榜数据保存在 leaderboard.json，删除此文件将清空所有记录
